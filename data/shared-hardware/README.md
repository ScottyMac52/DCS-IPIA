# Shared hardware

The shipped pinned catalog/artwork lives under [shared-assets](../shared-assets/), with per-file provenance and integrity checks. This directory is a reserved historical location, not the runtime hardware catalog. User-authored drawing revisions live in the selected profile's `UserMappings` library and module snapshots. See [shared assets](../../docs/migration/internal-shared-assets.md) and [custom mappings](../../docs/custom-mappings.md).
