# Bundled font provenance

DejaVu Sans Regular, version 2.37, from the DejaVu fonts distribution (<https://dejavu-fonts.github.io/>). Subset with FontTools 4.61.1 to the same 198 Unicode codepoints as the existing DejaVuSans-HEIMDALL.ttf bold face. Original glyph outlines and font names are retained. The existing DejaVuSans-HEIMDALL.LICENSE.txt applies to both faces.

Regular source SHA256: ae7b7855e115a5966d8b1b3f80f254ccc117ec86f9965e202ee2940453837280

Regular subset SHA256: 4afd27977e5a0c90060648b8ae8392a4ab32c972da435b1960ae3a957e4d6749

The regular face supports authored normal captions; the existing bold face supports bold captions. Both are embedded resources and resolve Arial/sans-serif aliases in canonical display/scaled SVG rendering.
