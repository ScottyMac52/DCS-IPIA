# Snapshot fixtures

The [UH-1H characterization fixtures](uh-1h/) retain pinned source evidence for the original import/snapshot contract. Broader source/release parity fixtures live under [tests/Dcs.Ipia.Tests/Fixtures](../../tests/Dcs.Ipia.Tests/Fixtures/), including HueyParity. Portable snapshots are generated and round-tripped by regression tests; these reference inputs do not replace a user's saved data or establish all-controller in-game acceptance. See [Huey release acceptance](../../docs/migration/huey-release-acceptance.md).
