# UH-1H Phase 1 fixtures

The Phase 1 characterization tests use source excerpts from `ScottyMac52/DCS-UH-1H-Huey` commit `77d924cce220355860e8f026cff3524bac531e29`.

The covered behaviors are the Huey's GUID-independent MFD instance identity, MOZA hold modifier chord, added and removed inputs, cyclic axis bindings, and the Warthog collective's sparse invert filter. The fixture is evidence for the import/snapshot contract, not a claim of complete Huey release parity.
